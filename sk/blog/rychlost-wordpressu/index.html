Rýchlosť WordPressu: ako zrýchliť web pre Google (2026)

17. 9. 2026 · Šimon Štermenský · Nokto Studio

Rýchlosť WordPressu riešite v tomto poradí: jeden cache plugin (LiteSpeed Cache zdarma alebo WP Rocket), WebP formát obrázkov, menej pluginov (menej kódu), kvalitný hosting. Cieľ: LCP pod 2,5 sekundy, INP pod 200 ms, CLS pod 0,1 (Core Web Vitals). Pomalý web stráca zákazníkov aj pozície v Google.

Prečo je rýchlosť dôležitá

Google meria rýchlosť ako signál kvality (Core Web Vitals). Pomalý web má vyšší odchodovú mieru: polovica návštevníkov odchádza, ak sa stránka načítava dlhšie ako 3 sekundy. Na WordPress weboch je rýchlosť navyše problém číslo jedna, lebo šablóny a pluginy pridávajú veľa kódu.

Meranie: čo a ako merať

Používajte PageSpeed Insights (bezplatný). Dôležité tri metriky:

  • LCP (Largest Contentful Paint): čas načítania hlavného obsahu. Cieľ pod 2,5 s.
  • INP (Interaction to Next Paint): reakcia na klik. Cieľ pod 200 ms.
  • CLS (Cumulative Layout Shift): posúvanie obsahu pri načítaní. Cieľ pod 0,1.

Päť opráv, ktoré najviac posunú rýchlosť

  • Cache plugin: LiteSpeed Cache (zdarma) alebo WP Rocket (cca 50 EUR/rok). Rozdiel vidno hneď.
  • WebP obrázky
  • Menej pluginov: každý plugin pridáva CSS a JS. Vypnite a vymažte nepoužívané.
  • Kvalitný hosting
  • Lazy loading

Čo nerobiť (bežné chyby)

Nesťahujte päť cache pluginov naraz, bojujú navzájom. Neoptimalizujte rýchlosť na úkor funkčnosti (preťažanie AMP, odstránenie všetkých pluginov). A nepresúvajte web na lacnejší hosting, ak problém je v šablóne s 20 pluginmi.

Koľko rýchlosti stojí

Základné opravy (cache, obrázky, menej pluginov) zvládnem za 3 až 5 hodín (36 až 60 EUR jednorazovo). Väčšie zásahy (hosting, šablóna) riešim v rámci retainera od 120 EUR mesačne, kam patrí aj priebežné sledovanie rýchlosti.

FAQ

Najdôležitejšie odpovede na jednom mieste

LCP pod 2,5 sekundy, INP pod 200 ms, CLS pod 0,1. Google to meria cez Core Web Vitals a radí rýchlejšie weby výš.

Áno, pre weby s návštevníkmi z viacerých krajín. Pre slovenský web s lokálnym publikom je najprv cache a obrázky, CDN potom.

Najčastejšie: ťažká šablóna, veľa pluginov, neoptimalizované obrázky alebo slabý hosting. Cache rieši len jednu vrstvu.
